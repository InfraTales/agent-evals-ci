# Security policy

## Reporting a vulnerability

Please report security problems in private through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Don't open a public issue.

We'll reply within 7 days and keep you updated until it's fixed.

## Supported versions

Only the `main` branch gets fixes.

## Scope

This is sample code for learning. The security design is in [docs/security.md](docs/security.md). Review it, and run your own checks, before you use any of it in production.
